# PİXEL MİNECRAFT KOLEKSİYON 🎮⛏

## Klasör Yapısı

```
/
├── index.html
├── style.css
├── game.js
├── README.md
└── pmkimage/
    ├── karakterler/
    │   ├── herobrine.png
    │   ├── yusufte.png
    │   ├── technoblade.png
    │   ├── necronvo.png
    │   └── ersincaki.png
    └── paketler/
        └── sıradanpaket.png
```

## Kurulum

1. Tüm dosyaları aynı klasöre koy
2. `pmkimage/karakterler/` klasörüne karakter görsellerini ekle
3. `pmkimage/paketler/` klasörüne paket görselini ekle
4. `index.html` dosyasını tarayıcıda aç

> Görseller bulunamazsa otomatik pixel art yedek devreye girer.

## Özellikler

- Her 10 dakikada bir paket açma hakkı
- Her pakette 3 rastgele karakter
- Yıldız animasyonlu arka plan
- Konfeti efekti (yeni karakter açılınca)
- Filtre sistemi (Tümü / Toplanan / Eksik)
- İlerleme çubuğu ve istatistik paneli
- LocalStorage ile kayıt sistemi
- Kayıt sıfırlama butonu
- 2000×4000 paket görseli desteği

## Notlar

- Paket görseli 2000×4000 piksel desteklenir, üstten kırpılır
- Tüm kayıtlar tarayıcıda saklanır, silinmez
